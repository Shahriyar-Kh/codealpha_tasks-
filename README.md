# CodeAlpha Python Internship Tasks

A small collection of Python internship/practice tasks focused on **GUI programming, algorithmic thinking, and API integration**.

## Included Tasks

### Task 1 — Fibonacci Generator
A Python GUI exercise for generating Fibonacci sequences.

### Task 2 — Student Grade Tracker
A desktop exercise for capturing and working with student-grade data.

### Task 3 — Geolocation Tracker
A PyQt5 desktop application that:

- resolves the current public IP
- requests approximate IP-based geolocation
- displays latitude/longitude and location metadata
- renders maps with Folium
- provides map styles and recent-location history
- embeds the generated map in a Qt WebEngine view

## Technologies Practiced

Python · PyQt5 · Qt WebEngine · Requests · Folium · GUI Events · File/Map Rendering
